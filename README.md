# Rewind

Rewind is a fan-made social world project inspired by classic Rec Room-style experiences.  
It focuses on simple multiplayer spaces, user creation, and community interaction.

## 🌐 Website
This repo contains the official Rewind website.

## 📁 Pages
- Home
- About
- Download
- News

## 🎯 Goal
The goal of Rewind is to recreate a lightweight, nostalgic social experience where players can:
- Join rooms
- Meet others
- Explore simple user-made spaces (future feature)
- Build and share experiences (planned)

## 🚧 Status
Early development — website is currently the first step before game systems are added.

## ⚙️ Tech
- HTML
- CSS
- Static hosting (GitHub Pages compatible)

This is a fan project and is not affiliated with Rec Room.
